# 🚗 The Car Game

A simple and fun 2D car racing game built using Python and Pygame. Control your car, dodge incoming enemy vehicles, and try to achieve the highest score possible!

## 🎮 Features

- Smooth car movement using keyboard controls
- Randomly spawning enemy cars
- Collision detection and Game Over screen
- Score and High Score tracking
- Main Menu and Restart functionality
- Background music for menu and gameplay
- Moving road lane animations

## 📸 Gameplay

The player controls a car moving left and right across three lanes. Enemy cars continuously spawn and move downward. Avoid collisions and survive as long as possible to increase your score.

## 🛠️ Technologies Used

- Python 3
- Pygame
